## О проекте only
<p>Проект реализует сервис по регистрации и авторизации пользователей на сайте.</p>
<p>Проект выполнен на PHP и MySQL.</p>
<p>Регистрация пользователей осуществляется на основе введенных имени, номера телефона, эл.почты и пароля.</p>
<p>Зарегистрированный пользователь авторизуется по номеру телефона или email-адресу и паролю.</p>

## Инициализация проекта

<p>Для инициализации проекта необходимо выполнить настройки подключения к базе данных в файле конфигурации config.php (секция "Настройки БД") в папке vendor :</p><p>DB_HOST - хост базы данных (ip или localhost для локального сервера);</p><p>DB_USER - имя пользователя базы данных;</p><p>DB_PASS - пароль базы данных;</p><p>DB_NAME - имя создаваемой базы данных.</p>
<p>Запуск проекта осуществляется путем введения соответствующего url в адресной строке браузера.</p><p>При первом запуске будет создана указанная в  config.php база данных и таблица users,  необходимые для работы проекта.</p><p>Дальнейшая работа осуществляется через интерфейс пользователя.</p>
